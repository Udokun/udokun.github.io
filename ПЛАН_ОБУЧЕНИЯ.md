## 📚 Этап 2: SCSS (Стилизация и архитектура)

### Что изучаем:

#### 2.1 Переменные (`_vars.scss`)
```scss
$accent: #ff7b44;        // Основной цвет
$text: #222;             // Цвет текста
$container: 1200px;      // Максимальная ширина
```

#### 2.2 Миксины (`_mixins.scss`)
- `@mixin container` - центрирование контента
- `@mixin respond($size)` - медиа-запросы
- `@mixin flex-center` - центрирование через flex

#### 2.3 Вложенность (Nesting)
```scss
.btn {
  padding: 12px;
  
  &--primary {  // .btn--primary
    background: $accent;
  }
  
  &:hover {     // .btn:hover
    transform: translateY(-2px);
  }
}
```

#### 2.4 Архитектура файлов
```
scss/
├── base/          - Переменные, миксины, сброс стилей
├── components/    - Переиспользуемые компоненты (кнопки, карточки)
└── section/       - Стили для конкретных секций страницы
```

### Практика:
- Доработаем стили для всех секций
- Добавим адаптивность (mobile-first)
- Создадим красивые анимации

## 📚 Этап 3: JavaScript (Интерактивность)

### Что изучаем:

#### 3.1 DOM (Document Object Model)
- `document.querySelector()` - выбор элементов
- `document.getElementById()` - выбор по ID
- `element.addEventListener()` - обработка событий

#### 3.2 События
- `click` - клик по элементу
- `submit` - отправка формы
- `scroll` - прокрутка страницы

#### 3.3 Манипуляции с DOM
- `element.innerHTML` - изменение содержимого
- `element.classList.add/remove` - управление классами
- `element.style.property` - изменение стилей

#### 3.4 Работа с данными
- Массивы и объекты
- `JSON.stringify()` / `JSON.parse()`
- `fetch()` - запросы к серверу

### Практика:
- Динамическая загрузка туров
- Плавная прокрутка к секциям
- Валидация форм
- Анимации при скролле
