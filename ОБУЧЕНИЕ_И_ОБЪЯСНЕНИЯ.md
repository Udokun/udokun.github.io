# 📚 Обучение и объяснения кода Vibe Tour

## 🎯 Что мы изучили и реализовали

### 1. HTML - Структура страницы

#### Семантические теги
```html
<header>  <!-- Шапка сайта -->
<section> <!-- Секция контента -->
<nav>     <!-- Навигация -->
<footer>  <!-- Подвал -->
```

**Почему это важно?**
- Поисковые системы лучше понимают структуру
- Улучшается доступность для людей с ограниченными возможностями
- Код становится более читаемым

#### Формы
```html
<form class="contact__form">
  <input type="text" required>
  <textarea required></textarea>
  <button type="submit">Отправить</button>
</form>
```

**Атрибуты:**
- `required` - обязательное поле
- `type="text/tel/email"` - тип данных
- `type="submit"` - кнопка отправки формы

### 2. SCSS - Стилизация

#### Переменные (`_vars.scss`)
```scss
$accent: #ff7b44;        // Основной цвет
$text: #222;             // Цвет текста
$container: 1200px;      // Максимальная ширина
```

**Зачем?**
- Легко менять цвета по всему сайту
- Единообразие дизайна
- Быстрая настройка темы

#### Миксины (`_mixins.scss`)
```scss
@mixin container {
  max-width: $container;
  margin: 0 auto;
  padding: 0 16px;
}

// Использование:
.header {
  @include container;
}
```

**Что это?**
- Переиспользуемые блоки кода
- Как функции в программировании
- Уменьшают дублирование

#### Вложенность (Nesting)
```scss
.btn {
  padding: 12px;
  
  &--primary {  // .btn--primary
    background: $accent;
  }
  
  &:hover {     // .btn:hover
    transform: translateY(-2px);
  }
}
```

**Преимущества:**
- Код более структурированный
- Легче читать и поддерживать
- Меньше ошибок

#### Медиа-запросы (Адаптивность)
```scss
@mixin respond($size) {
  @if $size == phone {
    @media (max-width: 600px) { @content; }
  }
}

// Использование:
.header {
  padding: 20px;
  
  @include respond(phone) {
    padding: 12px;  // На мобильных меньше отступ
  }
}
```

**Mobile-First подход:**
1. Сначала стили для мобильных
2. Потом добавляем стили для больших экранов
3. Сайт работает на всех устройствах

### 3. JavaScript - Интерактивность

#### DOM (Document Object Model)
```javascript
// Выбор элемента
const tourList = document.getElementById('tour-list');

// Создание элемента
const card = document.createElement('div');
card.className = 'tour-card';

// Добавление в DOM
tourList.appendChild(card);
```

**Что такое DOM?**
- Представление HTML в виде дерева объектов
- JavaScript может изменять структуру страницы
- Динамическое обновление контента

#### События (Events)
```javascript
// Обработка клика
link.addEventListener('click', function(e) {
  e.preventDefault();  // Отменяем стандартное поведение
  // Наш код
});

// Обработка отправки формы
form.addEventListener('submit', function(e) {
  e.preventDefault();
  // Валидация и отправка
});
```

**Типы событий:**
- `click` - клик мышью
- `submit` - отправка формы
- `scroll` - прокрутка страницы
- `load` - загрузка страницы

#### Массивы и объекты
```javascript
const toursData = [
  {
    id: 1,
    title: "Горное приключение",
    price: "от 3500₽"
  }
];

// Перебор массива
toursData.forEach(tour => {
  console.log(tour.title);
});
```

**Структуры данных:**
- **Массив** `[]` - список элементов
- **Объект** `{}` - набор свойств
- **forEach** - перебор элементов

#### Intersection Observer (Анимации при скролле)
```javascript
const observer = new IntersectionObserver(function(entries) {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      // Элемент виден на экране
      entry.target.style.opacity = '1';
    }
  });
});

observer.observe(element);
```

**Что делает?**
- Отслеживает видимость элементов
- Запускает анимации при появлении
- Улучшает производительность

## 🏗️ Архитектура проекта

### Структура SCSS
```
scss/
├── base/          # Основа (переменные, миксины)
├── components/    # Переиспользуемые компоненты
└── section/       # Стили для конкретных секций
```

**Принцип:**
- Разделение на логические части
- Легко найти нужный стиль
- Простое добавление новых компонентов

### Модульность JavaScript
```javascript
// Отдельные функции для разных задач
function loadTours() { ... }
function initSmoothScroll() { ... }
function initContactForm() { ... }

// Инициализация при загрузке
document.addEventListener('DOMContentLoaded', function() {
  loadTours();
  initSmoothScroll();
  initContactForm();
});
```

**Преимущества:**
- Код организован
- Легко тестировать
- Простое добавление функций

## 🎨 Дизайн-концепции

### Цветовая схема
- **Акцентный цвет** (`$accent`) - для важных элементов
- **Текст** (`$text`) - основной цвет текста
- **Светлый фон** (`$bg-light`) - для карточек

### Типографика
- **Заголовки** - крупные, жирные
- **Текст** - средний размер, читаемый
- **Отступы** - достаточные для комфорта

### Анимации
- **Плавные переходы** - `transition: 0.3s ease`
- **Hover эффекты** - реакция на наведение
- **Появление при скролле** - динамика страницы

## 📱 Адаптивность

### Breakpoints (Точки перелома)
```scss
phone:  max-width: 600px   // Мобильные
tablet: max-width: 900px   // Планшеты
desktop: от 1200px         // Десктопы
```

### Стратегия
1. **Mobile-First** - начинаем с мобильных
2. **Прогрессивное улучшение** - добавляем для больших экранов
3. **Гибкая сетка** - Grid и Flexbox
