# 🌓 Система тем Vibe Tour

## Что реализовано

### ✅ Две темы
- **Светлая тема** (по умолчанию) - белый фон, темный текст
- **Темная тема** - темный фон, светлый текст

### ✅ Цветовая палитра

#### Светлая тема:
- Акцент: **#ff6b35** (теплый оранжевый)
- Фон: белый (#ffffff)
- Текст: темно-серый (#1a1a1a)

#### Темная тема:
- Акцент: **#ff8c66** (светлый оранжевый)
- Фон: темно-серый (#1a1a1a)
- Текст: светло-серый (#e8e8e8)

### ✅ Переключатель темы
- Кнопка в header справа
- Иконка меняется (луна/солнце)
- Текст меняется ("Тёмная"/"Светлая")
- Сохранение выбора в localStorage

### ✅ Автоматическое определение
- Определяет системную тему пользователя
- При первом посещении использует системную тему
- Сохраняет выбор пользователя

## Как использовать

1. **Скомпилируйте SCSS:**
   ```bash
   sass scss/style.scss css/style.min.css --watch
   ```

2. **Откройте сайт** - переключатель темы в header справа

3. **Кликните на переключатель** - тема изменится мгновенно

## Технические детали

### CSS переменные
Все цвета теперь через CSS переменные:
```css
--accent: #ff6b35;
--text-primary: #1a1a1a;
--bg-primary: #ffffff;
```

### Переключение
Атрибут `data-theme` на `<html>`:
- `data-theme="light"` - светлая тема
- `data-theme="dark"` - темная тема

### JavaScript
- `initThemeToggle()` - инициализация
- `updateThemeIcon()` - обновление иконки
- Сохранение в `localStorage.getItem('theme')`

## Настройка цветов

Измените цвета в `scss/base/_vars.scss`:
```scss
:root {
  --accent: #ff6b35;  // Ваш цвет
}

[data-theme="dark"] {
  --accent: #ff8c66;  // Ваш цвет для темной темы
}
```
