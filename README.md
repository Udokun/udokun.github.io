# Vibe Tour - Лендинг для туров выходного дня

Современный лендинг для туристического агентства, разработанный с использованием HTML, SCSS и JavaScript.

## 🚀 Быстрый старт

### Компиляция SCSS в CSS

Для работы с проектом необходимо скомпилировать SCSS файлы в CSS. Есть несколько способов:

#### Вариант 1: Использование Sass CLI
```bash
# Установка Sass (если еще не установлен)
npm install -g sass

# Компиляция один раз
sass scss/style.scss css/style.min.css

# Компиляция с отслеживанием изменений (watch mode)
sass scss/style.scss css/style.min.css --watch
```

#### Вариант 2: VS Code расширение "Live Sass Compiler"
1. Установите расширение "Live Sass Compiler" в VS Code
2. Нажмите "Watch Sass" внизу панели статуса
3. Файлы будут компилироваться автоматически при сохранении

#### Вариант 3: Использование Gulp или других сборщиков
Можно настроить автоматическую сборку через Gulp, Webpack и т.д.

## 🎨 Особенности

- ✅ Полностью адаптивный дизайн (mobile-first)
- ✅ Плавная прокрутка к секциям
- ✅ Анимации при скролле
- ✅ Динамическая загрузка туров через JavaScript
- ✅ Валидация форм
- ✅ Современный стек: HTML5, SCSS, ES6+

## 📱 Адаптивность

Сайт оптимизирован для:
- 📱 Мобильных устройств (от 320px)
- 📱 Планшетов (до 900px)
- 💻 Десктопов (от 1200px)

## 🛠️ Технологии

- **HTML5** - семантическая разметка
- **SCSS** - препроцессор CSS с переменными и миксинами
- **JavaScript (ES6+)** - интерактивность и динамический контент
- **CSS Grid & Flexbox** - современная верстка

## 📝 Основные функции JavaScript

- `loadTours()` - загрузка туров на страницу
- `initSmoothScroll()` - плавная прокрутка к якорям
- `initContactForm()` - валидация формы контактов
- `initScrollAnimations()` - анимации при скролле
